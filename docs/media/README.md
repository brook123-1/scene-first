# Public media policy

Only synthetic fixtures, architecture diagrams, or screenshots created entirely from mocked/synthetic data may be stored here.

Do not copy media from `.local/`, benchmark source photos, real face/head crops, generated derivatives of real people, browser traces, or screenshots containing local paths, credentials, personal data, private domains, or unclear visual assets. Inspect image metadata before every commit.

The primary README currently uses Mermaid and no promotional screenshot. The initial public repository contains only deterministic geometric placeholders; any future promotional visual must have its own recorded rights and metadata review.
