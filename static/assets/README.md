# Deterministic public placeholders

The safe-cover PNG files and PWA icon files in this directory are deterministic geometric placeholders generated by:

```powershell
.venv\Scripts\python.exe scripts\generate_public_placeholders.py
```

The generator uses only Pillow drawing primitives, solid project colors, and no fonts, external artwork, training model, or third-party brand element. These generated files are part of the project source distribution under Apache-2.0.

The legacy safe-cover filenames are retained for API compatibility; their artwork is intentionally neutral and does not depict a profession or an identifiable person.
