# Public roadmap

Scene First is an active experimental project. Priorities are ordered by safety and maintainability, not promised release dates.

## Near term

- Make the clean Windows setup and local-only path easier to diagnose.
- Add explicit runtime-data inspection and deletion controls.
- Expand deterministic synthetic coverage for missed people, overlap, crop validation, and metadata removal.
- Publish a provider conformance checklist for crop scope, mask support, timeouts, and error redaction.
- Maintain fail-closed asset imports and require explicit redistribution evidence for every non-generated public visual pack.

## Later, only with evidence

- Mature Local Master after broader browser and memory testing.
- Evaluate pose-aware avatar overlay with rights-cleared assets and consented local research, without committing real photos.
- Improve accessible mobile review and manual region editing.
- Document reproducible self-hosting hardening for operators who intentionally run a remote service.

## Not a promise

This roadmap does not promise hosted generation, free third-party API calls, perfect detection, guaranteed anonymity, a 3D avatar system, or a production SLA.
